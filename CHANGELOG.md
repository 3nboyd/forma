# Changelog

## 1.0.0

- Initial native macOS release with twelve local file tools.
- Image format conversion, resizing, centered crop presets, rotation and photo filters.
- PDF merge, page extraction, password protection and removal, text extraction and page rendering.
- Optional FFmpeg audio/video conversion with trim and quality settings.
- Document conversion, ZIP creation, and collision-safe file copy/move.
- Drag-and-drop queue, destination selection, keyboard shortcuts, dark appearance and Finder reveal.
- Conversion and filesystem safety integration tests, CI and app packaging.
